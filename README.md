# Omolade & Tomiwa

Wedding invitation site for Saturday, 27 February 2027, at Funplex Resort, Magodo.

- The built site sits at the repository root and is served by GitHub Pages.
- `source/` holds the Vite + React Three Fiber source. Personal content lives in `source/src/config.js`.
- To rebuild, run `npm install` and `npx vite build` in `source/`. Then copy `dist/app.js` to the root, and replace the `<style>` block in `index.html` with `dist/style.css`.
